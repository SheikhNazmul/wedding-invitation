# Wedding Invitation — Sheikh Nazmul Islam & Maria Akter Tania

Digital wedding reception invitation website (single self-contained `index.html`).

- **Groom:** Sheikh Nazmul Islam — AI/ML Engineer, CSE, Daffodil International University
- **Bride:** Maria Akter Tania
- **Reception:** Sunday, 22 November 2026, 7:00 PM – 11:00 PM
- **Venue:** Asian Convention Center, Hazaribag, Dhaka
- **Maps:** https://maps.app.goo.gl/YxVPJa15cjTkWrBm8

## Features
- Greeting-card / envelope opening screen
- Live countdown to the reception
- Groom & bride cards with animated 3D avatars
- Venue section with Google Maps link
- Guest activity: upload a photo, get a cartoon-style wedding frame ("দোয়া করি, শুভ হোক" — "শেখ নাজমুল ইসলামের পক্ষ থেকে"), download it as PNG. Photos are processed only in the visitor's browser and are never uploaded.

Open `index.html` in any browser to view the site.
